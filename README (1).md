# Week 5 - AI Internship
## Deep Learning & Neural Networks

### Contents
- **Project_Report.pdf** — Task 1 write-up (Deep Learning fundamentals, ANN diagram, working flow), plus explanations and real results for Tasks 2-4, and the Mini Project report.
- **Week5_NeuralNetwork.ipynb** — Tasks 2, 3 & 4: a basic ANN built with TensorFlow/Keras on the Iris dataset (4 input features → 2 hidden layers → 3-class softmax output), trained for 80 epochs, with accuracy/loss graphs, confusion matrix, and predictions.
- **Mini_Project_Breast_Cancer.ipynb** — Task 5: a complete deep learning classification project predicting malignant vs benign tumors using the Breast Cancer Wisconsin dataset.
- **iris.csv** — Iris flower dataset (150 samples, 3 species). Source: Scikit-learn built-in dataset.
- **breast_cancer.csv** — Breast Cancer Wisconsin dataset (569 samples, 30 features). Source: Scikit-learn built-in dataset.
- **Screenshots/** — Output screenshots from running both notebooks.
